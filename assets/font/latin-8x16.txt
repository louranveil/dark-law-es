# Latin font of the Dark Law Spanish translation: ink source, prototype 1.
#
# Original work of this project (MIT, like the rest of the repository); no glyph was copied from another font.
# Format (read by tools/build_custom_font.py; see docs/fonts/custom-font.md):
#   glyph <char|U+XXXX> top=<row> left=<column>   then pixel rows ('X' ink, '.' empty) until a blank line
#   mark <name> <x>,<y> <x>,<y> ...               a set of ink pixels placed in cell coordinates
#   compose <char> <base char> <mark>             the base glyph plus the mark
#   flip <char> <source char> <first row> <last row>   the source glyph flipped vertically between those rows
#   rotate <char> <source char> <first row> <last row> <first column> <last column>   the source glyph turned 180 degrees in that box
# The cell is 8x16 (columns 0-7, rows 0-15, advance 8). Capitals and ascenders occupy rows 3-12, the x-height
# starts at row 6, descenders reach row 15, accents on capitals use rows 0-1 and on lowercase letters rows 3-4.
