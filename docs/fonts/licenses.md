# Font Licenses

Status: **verified** for what was read from the official sources listed below on 2026-11-20; every point that could not be verified is marked as such. This is a technical reading of the licence texts, not legal advice.

The question asked of each font is whether its glyphs may be modified and redistributed inside a translation patch. Converting a bitmap font into the 8x16 cell with an outline (see [evaluation.md](evaluation.md)) modifies the glyphs, and the BPS patch then carries the resulting bytes, so both permissions are needed. The ROM itself is never distributed.

## Per Font

### Sweet16 and Sweet16mono

- Source: <https://github.com/kmar/Sweet16Font>, commit `8c56c21` (2020-09-30). Files read: `LICENSE`, `README`.
- The `LICENSE` file is the Boost Software License 1.0. The `README` states the licence in its second line and adds "meaning you don't have to give credit/embed license". The copyright line is `(c) 2018 Martin Sedlák`.
- The Boost licence grants the right to "prepare derivative works" and to redistribute. Its notice requirement does not apply "unless such copies or derivative works are solely in the form of machine-executable object code generated by a source language processor". A patch that carries glyph bitmaps is not obviously that form, so the project should include the notice anyway; it costs one line in the credits.
- The glyph bitmaps are the original `.f8` files (`Sweet16mono.f8`, `Sweet16.f8`) made by the author with his own editor; the `README` history says he drew the font himself.
- Files used: `Sweet16mono.f8` (SHA-256 `68751caf563b1ac3f7c88abb390ccd73cd3613c9d0d00a78bc352015317ae881`), `Sweet16.f8` (`a99250126e79da4d15779f769a0be8b79f290dd0928815c22f3ddf0c3c04bdc3`), `Sweet16_charwidths.txt`.

### Spleen

- Source: <https://github.com/fcambus/spleen>, commit `a6916ff`, release 2.3.0 (2026-11-17). Files read: `LICENSE`, `AUTHORS`, `README.md`.
- BSD 2-Clause, `Copyright (c) 2018-2026, Frederic Cambus`. Redistribution in binary form "must reproduce the above copyright notice, this list of conditions and the following disclaimer in the documentation and/or other materials provided with the distribution". For a patch, that means the notice goes in the documentation shipped with it.
- Files used: `spleen-8x16.bdf` (SHA-256 `60fbfe34c51d3b3f92f68a286d1df719166d345acfeb266a57fd55e14fc1f8b9`), `spleen-6x12.bdf` (`1856974dc5f14f05549074b5d55c387bea0e954c9ee567c9732ce74ef5809930`).

### Terminus

- Source: <https://terminus-font.sourceforge.net/>, archive `terminus-font-4.49.1.tar.gz` downloaded from the SourceForge project. Files read: `OFL.TXT`, `README` section 7, the `COPYRIGHT` and `NOTICE` fields of the BDF files.
- `OFL.TXT` opens with "Copyright (C) 2020 Dimitar Toshkov Zhekov, with Reserved Font Name "Terminus Font"" and then the SIL Open Font License 1.1. The BDF files repeat the copyright and say "Licensed under the SIL Open Font License, Version 1.1".
- Consequences of the OFL for this project:
  - Modification is allowed. Converting to the game's cell with an outline produces a Modified Version, which may not use the Reserved Font Name; the patch and its documentation must not call the result "Terminus".
  - Condition 5 of the OFL requires that the font software, "modified or unmodified, in part or in whole, must be distributed entirely under this license". The glyph bytes inside the patch are therefore under the OFL, while the rest of the patch can keep the project licence. Whether a BPS patch containing glyph bytes counts as "bundling with software" is **not settled** by the licence text; the conservative reading is to ship `OFL.TXT` and the copyright with the patch.
  - The font may not be sold by itself. A free patch does not sell it.
- The `README` of the archive also mentions the GNU General Public License for the build scripts, not for the glyphs. This was not examined further.
- Files used: `ter-u16n.bdf` (SHA-256 `5197662b22bf9f3e68d4af9f969a7fefa3edae40dd82ae969a147381130fb4ae`), `ter-u12n.bdf` (`9e942cad8173fddf34fc8a784e9ec6d2d4cfb8b82363faf65f43b236fe2f5a99`).

### Cozette

- Source: <https://github.com/the-moonwitch/Cozette> (the repository formerly published as `slavfox/Cozette`; both URLs resolve to the same history), commit `4808ce9`, release `v.1.30.0`. Files read: `LICENSE`, `README.md`.
- MIT, `Copyright (c) 2020 Samhain <samhain@moonwit.ch> & contributors`. The `README` says "Cozette is licensed MIT".
- Not verified: the `README` says the font is "based on Dina, which itself is based on Proggy" and "heavily inspired by Creep". The licence terms of Dina and Proggy were not checked here, so the MIT claim for the glyph shapes rests on the author's statement. This is why Cozette is accepted with a caveat and not ranked above the fonts with a clean, self-contained origin.
- File used: `cozette.bdf` from the release (SHA-256 `8d740166af3a14053773ac7a8846bf288c8818a44f73ab28d4725d91b03a5639`).

### Monogram

- Source: <https://datagoblin.itch.io/monogram> (the itch.io page, read through a scraper). The page says "Monogram is a monospace bitmap font, free and CC0" and lists "Asset license: Creative Commons Zero v1.0 Universal". The author's reply in the comments says the font is public domain and that distributing a variant is fine. The author credited on the mirror used for the BDF is Vinícius Menézio.
- The itch.io download needs an interactive "name your own price" step, so the BDF used here is the one published by the FontPixel catalogue (<https://fontpixel.com/en/fonts/monogram/>), whose page reproduces the CC0 text and cites the itch.io page as source. The converted bitmap was not compared against the author's own TTF; treat the mirror as a convenience copy. SHA-256 of the BDF: `ed24375246928661f652a945c815e44b6a90e8e2aa79ab41aea95a9f6cc560ff`.
- The font is 5 pixels wide by 9 tall, much smaller than the game cell (see [evaluation.md](evaluation.md)).

### Unscii

- Source: <https://viznut.fi/unscii/>, page read on 2026-11-20. It says "`unscii-16-full` falls under GPL because of how Unifont is licensed; the other variants are in the Public Domain". The variant evaluated is `unscii-16.hex` (SHA-256 `2642c8b748fa81f24d76772d70c55faa720d98fadfec8133daf89136c5c8bfb1`), which is not the `-full` variant, so it is public domain according to the author. The `-full` variants must never be used.
- The page also says the glyphs are "based on classic system fonts" that the author studied. That is how the author describes his own redrawing, and it is not a licence statement; no per-glyph provenance was checked.

### Pixel Operator

- The original site, `pixeloperator.com`, now serves a domain-for-sale page, and the repository named in older notes (`notabug.org/HarvettFox96/ttf-pixeloperator`) returns 404 according to a third party; the author's current personal site (<https://tilde.club/~harvettfox96/>) was only checked at its home page, which does not mention the font; the `pages/` and `fonts/` paths guessed on it returned 404. The licence statement therefore comes from the author's own notes on DaFont (<https://www.dafont.com/pixel-operator.font>): "Changed licence to Creative Commons Zero (CC0) 1.0" and "This typeface is made by Jayvee Enaguas (HarvettFox96), licensed under a Creative Commons Zero (CC0) 1.0". The zip downloaded from DaFont contains `LICENSE.txt` with the CC0 1.0 legal text. FontLibrary also lists CC-0.
- Caveat: there is no primary repository any more, and older releases (2009-2018) were published under other licences according to a mirror snippet; only the DaFont release carries the CC0 statement. Accepted, but a single source.
- File used: `PixelOperator.ttf` from that zip (SHA-256 `8d805274eaf227855147153182a96a86ff395ddbc7d2d378095af8831b764a3e`); rasterized with Pillow at 16 px without antialiasing.

### Orp (rejected on licence grounds)

- Source: <https://github.com/MicahElliott/Orp-Font>, commit `7f35463` (2017-10-18). The repository has **no licence file**. Each BDF carries `COPYRIGHT "Public domain terminal emulator font. Share and enjoy."`, a sentence inherited from Markus Kuhn's `ucs-fonts` project, and the `README` says "Orp Medium (adapted from Pro Font with various changes)" and calls the package a fork of the Unicode fonts for X11.
- ProFont (Tobias Jung) is published under the MIT licence since 2014 according to <https://tobiasjung.name/profont/>, and MIT requires the copyright notice to be kept. A work adapted from an MIT font cannot simply be declared public domain, and the Orp repository gives no explanation. The FontPixel catalogue labels Orp as public domain, but it says itself that this is an unofficial summary and that "the upstream original text prevails".
- Decision: not accepted. It would need either a statement from the author or the ProFont notice and a check of the derivation. It is not needed, because Cozette and Spleen cover the 6x12 size.

### Departure Mono

- Source: <https://departuremono.com/> and <https://github.com/rektdeckard/departure-mono>, release `v1.500` (2025-05-25), asset `DepartureMono-1.500.zip`. Files read: `LICENSE` and `README.md` inside the zip, and `README.md` of the repository.
- The `LICENSE` in the zip opens with "Copyright 2022–2024 Helena Zhang (helenazhang.com)" and "This Font Software is licensed under the SIL Open Font License, Version 1.1". The copyright line does not declare a Reserved Font Name; the text "Reserved Font Name" appears only inside the licence definitions. The `README` of the repository has a table that gives the font as SIL OFL and the **site** as MIT (Helena Zhang and Tobias Fried); the `LICENSE` at the root of the repository is the MIT licence of the site and does not apply to the font, which is easy to misread.
- The OFL consequences are the same as for Terminus (see above): the glyph bytes of a converted font are a Modified Version, must stay under the OFL, and the patch documentation should ship the OFL text and the copyright. Because no Reserved Font Name is declared, the name restriction does not formally apply, but the conservative choice is to not call the converted font "Departure Mono".
- The font is an OpenType file with outlines designed on an 11-pixel grid (the `README` asks for sizes in increments of 11 px). It was rasterized with Pillow at 11 px without antialiasing. File used: `DepartureMono-Regular.otf` (SHA-256 `4d53f663155cf8bf7ffc8e688776e719625f7bbb80a8d90073438b249261a2e0`).

## Attribution Block For The Release

If Sweet16 is chosen, the documentation shipped with the patch should carry at least:

```text
Font: Sweet16mono, (c) 2018 Martin Sedlák, Boost Software License 1.0,
https://github.com/kmar/Sweet16Font. Glyphs adapted to an 8x16 cell with outline.
```

If Departure Mono is chosen, add the text of the SIL OFL 1.1 and:

```text
Font: Departure Mono, Copyright 2022-2024 Helena Zhang, SIL Open Font License 1.1,
https://departuremono.com/. Glyphs rasterized at 11 px and adapted to an 8x16 cell with outline.
```

Any other candidate adds its own notice from the table above.
